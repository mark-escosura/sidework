Side Work

Set up the confirmation email

Do this in the Supabase dashboard on your iPhone. It takes a few minutes. Don’t change anything else unless a step says to.

1. Fix the link destination

  1. Open Safari and go to supabase.com/dashboard. Sign in.
  2. Open the side-work project.
  3. If you don’t see a sidebar, tap the menu (three lines).
  4. Tap Authentication, then URL Configuration.
  5. Set Site URL to:
    https://mark-escosura.github.io/sidework/
  6. Under Redirect URLs, add all three if they aren’t already there:
    https://mark-escosura.github.io/sidework/
    https://mark-escosura.github.io/sidework
    https://mark-escosura.github.io/sidework/index.html
    If you still see the old /tip-tracker/ address, remove it after the new ones are saved.

2. Turn on leaked password protection

  1. Still under Authentication, open Sign In / Providers and tap Email. If you don’t see it there, check Authentication → Settings for password security.
  2. Turn Leaked password protection on.
  3. Confirm the minimum password length is 8.

3. Paste the Side Work email

  1. Tap Authentication, then Email Templates, then Confirm signup.
  2. Set the Subject to exactly:
    Confirm your Side Work account
  3. Tap the box below, then tap Copy template. The whole HTML should copy.
  4. Go back to the Supabase template body, select everything in that box, and paste.
  5. Leave {{ .ConfirmationURL }} as-is. Don’t edit the link.
  6. Save.

Template to copy

Copied. Switch to Supabase and paste it into the template body.

Plain-text wording (if you ever see a separate plain-text box) is at confirm.txt. Most of the time you only paste the HTML. The raw file is also at confirm.html.

4. What this does not change by itself

The From name and address will still look like Supabase (often noreply@mail.app.supabase.io) until you add custom SMTP later, for example Resend, Postmark, or a Gmail mailbox you control. That’s a separate step, with a sender you choose. The new subject and body already say Side Work, which is the part coworkers see first.

After you paste the template, send yourself a test sign-up and confirm the link opens https://mark-escosura.github.io/sidework/ and shows a friendly “You’re in” or sign-in screen — not an error or localhost.
